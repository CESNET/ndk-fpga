AXI Tools
=========

Components using the AXI-Stream bus are typically located in the ``comp/axis_tools/`` directory in the OFM repository.
Bus converters, for example, MFB to AXI-Stream, may be located in the other bus' directory (e.g., ``comp/mfb_tools/axi/mfb2axi/``).
