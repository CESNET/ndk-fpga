Gen Loop Switch

The `Generator/Loopback Switch` (Gen Loop Switch/GLS for short) is a FW component for testing/debugging purposes.
It is able to switch between multiple inputs for each of the outputs, either by forwarding one stream's input, looping back the other stream's input or using some form of a packet generator.
The component is located in `ndk-fpga/comp/mfb_tools/debug/gen_loop_switch`; more info can be found there.
